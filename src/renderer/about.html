About AeroMoveX

AeroMoveX is a sleek, modern flight tracking dashboard dedicated to visualizing air traffic within Bangladesh Airspace.

Built with Electron and Leaflet, the application provides real-time and simulated insights into aircraft movements, telemetry (speed, altitude, heading), and active routes across major airports like Dhaka (DAC), Chattogram (CGP), and Sylhet (ZYL).

Features

  • Live map rendering locked to Bangladesh bounds
  • Real-time telemetry and flight progress tracking
  • Saved Flights Watchlist
  • Modern, premium UI design
